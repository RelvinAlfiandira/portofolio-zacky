# Personal Portfolio - Muhammad Zacky Al Ghifari

Website portofolio personal yang dibangun menggunakan **Next.js (App Router)**, **Tailwind CSS**, dan **Lucide React**. Portofolio ini dirancang dengan gaya dark mode modern, responsif, dan mengutamakan estetika visual yang bersih serta interaktif.

---

## ✨ Fitur Utama

- **Hero Section**: Layout modern dengan foto latar belakang, tipografi tebal responsif, serta akses cepat ke *Download CV* dan kontak.
- **My Expert Area (Skill Marquee)**: Animasi running marquee halus (*infinite loop*) yang menampilkan daftar tech stack lengkap dengan logo brand resmi.
- **Featured Projects**: Tampilan kartu proyek minimalis dengan gambar utama, kategori, serta tombol tautan proyek (*View Project*).
- **What I Do (Focus Areas)**: Kartu kapabilitas dengan ikon *squircle* berukuran besar yang menjelaskan keahlian utama di bidang pengembangan backend dan web.
- **Responsive & Dark Mode First**: Dioptimalkan secara penuh untuk tampilan desktop maupun perangkat seluler.

---

## 🛠️ Tech Stack Portfolio

Website portofolio ini dibangun menggunakan teknologi berikut:

- **Framework**: [Next.js](https://nextjs.org/) (App Router - JavaScript)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/) & Brand Logos (Devicon / SimpleIcons)
- **Font**: Google Fonts (`next/font`)
